# SBUHack_F26
Stony Brook University hackathon, 10/23/26-10/25/26

## Steel Junction
A steam railway puzzle that teaches logic gates. Fit AND, OR, NOT and XOR signal boxes so the express departs exactly when the order says. Real railway signal boxes did this logic with iron levers long before computers.

Run it: open `index.html` in a browser. No build step.
Test the puzzle logic: `node logic.test.js`
