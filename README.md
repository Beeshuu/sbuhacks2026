# SBUHack_F26
Stony Brook University hackathon, 10/23/26-10/25/26

## Steel Mill
A steam-powered puzzle that teaches logic gates. Fit AND, OR and NOT valves so the piston fires exactly when the order says.

Run it: open `index.html` in a browser. No build step.
Test the puzzle logic: `node logic.test.js`
